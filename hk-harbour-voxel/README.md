# 维多利亚港 · 体素数字沙盘

**VOXEL VICTORIA HARBOUR** — 一个跑在浏览器里的香港维多利亚港微体素数字孪生沙盘。
纯静态、零依赖（只带一份 `three.min.js`），双击 `index.html` 即可运行。

```
体素规模   518 万实心体素 · 207 万贪心合并面片 · 414 万三角面 · 显存 ≈142 MB
世界尺度   1152 × 176 × 704 voxel ＝ 4.6 km(东西) × 704 m(高) × 2.8 km(南北)，1 voxel = 4 m
城市内容   58 座具名地标 · 2026 栋程序化楼宇（13 种建筑原型，含 829 栋半山台地住宅）· 4.8 万件街道细节
生成耗时   约 0.34 s 生成 + 1.5 s 贪心网格化（分帧执行，带进度条）
```

---

## 1. 运行

```
直接打开：  index.html            （file:// 协议即可，无需服务器）
或起个静态服务： python -m http.server 8080
```

**URL 参数**

| 参数 | 说明 |
|---|---|
| `scale=1.0` | 渲染分辨率倍率（默认取 devicePixelRatio，上限 1.6） |
| `t=20.5` | 初始世界时间（小时，0–24） |
| `weather=clear\|haze\|cloudy\|storm` | 初始天气 |
| `grid=0` `shadows=0` `refl=0` `rays=0` | 关闭体素网格线 / 动态阴影 / 海面反射 / 体积光 |
| `q=ultra\|high\|medium\|low` | 画质档位（同时决定分辨率倍率、阴影图尺寸、辉光与体积光强度、锐化） |
| `probe=1&views=harbour,central&shot=960` | 无头验证模式（见第 5 节） |

## 2. 操作

| 模式 | 操作 |
|---|---|
| **上帝视角** Orbit | 左键拖动旋转 · 右键拖动平移 · 滚轮缩放 · 点击建筑弹出资料卡 · `WASD`/方向键沿屏幕前后左右平移（`Shift` 加速）· `Q/E` 旋转 · `空格/C` 升降 |
| **第一人称** Walk | `WASD`/方向键行走 · `Shift` 疾跑 · `空格` 跳跃 · `F` 切换飞行 · 鼠标环视（点击锁定指针，`Esc` 释放） |
| **无人机** Drone | `WASD` 沿视线飞行（含俯仰）· `空格/C` 垂直升降 · `Shift` 加速 · 鼠标环视 |
| **电影巡游** Cinematic | 沿预设曲线自动飞行，`空格` 退出 |
| **天星小轮** Ferry | 挂在渡轮甲板上横渡维港 |

**移动手感按真实尺度标定**（1 voxel = 4 m）：步行 7.9 km/h、疾跑 23 km/h、
跳跃 1.15 m、重力 15.6 m/s²；飞行 58 / 202 km/h，无人机 43 / 173 km/h。
走路有加减速与双相头部起伏，飞行有惯性；撞墙会卸掉该轴速度，
1 voxel（4 m）以内的路缘与台阶会自动踏上去。切走窗口或松开指针锁会清空按键状态。

**经典机位**：数字键 `1`–`9`（或左侧面板 chips）一键直达——
维港全景 / 全城鸟瞰 / 中环天际线 / 太平山俯瞰 / 九龙半岛 /
尖沙咀海滨（第一人称）/ 弥敦道街头（第一人称）/ 铜锣湾避风塘 / 东区走廊。

全局快捷键：`Tab` 切换视角 · `L` 地标标签 · `G` 体素网格 · `H` 隐藏 UI · `P` 保存截图。
右侧小地图可点击传送，并实时显示地标、船只与摄像机视锥；左侧面板可搜索地标、
调时间/天气、切画质档位（极致/高/中/低）、拉辉光与**鼠标灵敏度**。

**关于第一人称"视角突然飞走"**：浏览器在进入指针锁定的一瞬间，会把光标从原位置
瞬移到画面中心，并把这段距离当作一次 `movementX/Y` 事件发出来（可达上千像素）。
现在的做法是：锁定后 120 ms 内的移动事件全部丢弃、单次事件位移上限 150 px、
优先申请 `unadjustedMovement`（绕过系统鼠标加速曲线，瞄准更线性），
并在长时间旋转后对 yaw 取模防止精度流失。

## 3. 代码结构

按依赖顺序加载（`index.html` 里的 `<script>` 顺序即依赖顺序）：

| 文件 | 职责 |
|---|---|
| `src/core.js` | 世界常量、材质调色板（62 种材质 × 9 类渲染语义）、确定性随机、值噪声、折线插值 |
| `src/volume.js` | 稀疏分块体素体（32³ chunk）、DDA 射线拾取、盒体碰撞、**分帧贪心网格化 + AO** |
| `src/geo.js` | 维港地理底图：两岸海岸线折线、填海区、太平山与九龙丘陵、海床、岸线距离场、用地类型 |
| `src/build.js` | 体素笔刷库：`tower / taper / cyl / dome / triPrism / shellRoof / bandFacade / ribFacade / acUnits / rooftop / neonSign / roofSign / tree / palm / lamp / pier` |
| `src/archetypes.js` | **非地标建筑的品种库（13 种原型）**：唐楼（骑楼+阳台+招牌）· 旧式洋楼（圆角+腰线）· 公屋长条（彩色油漆带+外突电梯井+晒衣杆）· 十字型公屋 · 风车形私宅（凸窗+车库裙楼）· 玻璃写字楼 · 石材写字楼 · 工业大厦（外露框架+山墙广告+屋顶水塔）· 商场（LED 幕墙+天窗）· 多层停车场（层层横缝+螺旋坡道）· 酒店（裙楼+塔楼+天台招牌）· 学校（L 形+操场+旗杆）· 村屋 / 庙宇（坡瓦顶）。按分区性格、地块尺寸、临街位次加权抽签 |
| `src/landmarks.js` | 50 座地标的逐座还原（中银、汇丰、ICC、会展、钟楼、太空馆、体育馆…） |
| `src/extra.js` | 追加 8 座：港岛东中心、太古坊、东区走廊高架、山顶缆车、中环街市、中央图书馆、崇光、理工大学 |
| `src/city.js` | 城市肌理：主干道网、分区性格填充、**半山台地住宅**、海滨长廊、公园、货运码头、空中连廊、弥敦道霓虹峡谷 |
| `src/detail.js` | 微观加细：天台屋、竹棚、晾衣杆、骑楼雨棚、电车架空线、斑马线与交通灯、庙街夜市、码头家具、街道家具、天台花园 |
| `src/gfx.js` | 全部 GLSL：体素材质（调色板查表 + 窗格/圆窗/LED/植被程序纹理 + 阴影 + 雾）、天空、海面、光束、雨、Bloom、ACES 合成 |
| `src/entities.js` | 动态实体：天星小轮/张保仔/货柜船/拖轮/快艇、220 辆车流、电车、摩天轮、直升机与客机、幻彩咏香江光束、雨幕 |
| `src/ui.js` | HUD：加载进度、控制面板、地标清单与信息卡、3D 标签防重叠、小地图、罗盘、性能读数 |
| `src/app.js` | 装配与主循环：五种镜头、时间/天气系统、多通道渲染、体素拾取、无头探针 |

**渲染管线（每帧）**

```
阴影贴图（1024~3072² 正交按画质档位，跟随视野收紧；每像素随机旋转的 8 抽样圆盘
          + 斜率自适应偏移，静态城市与车流/电车/船只/摩天轮在同一遍写入）
  → 海面平面反射（半分辨率，镜像相机 + BackSide）
  → HDR 主通道（half-float，体素材质在着色器里画窗格/亮窗/霓虹/植被扰动）
  → Bloom：亮度提取（软膝）→ 5 级降采样（每级横竖高斯）→ 渐进上采样合成一张柔光图
  → 体积光：以太阳的屏幕位置为中心对辉光层做 16 步衰减径向行进（上帝之光）
  → ACES 合成（曝光/对比/饱和/lift/暗角/FXAA/对比自适应锐化/颗粒 + 1/255 抖动）
```

体素几何全部由 **贪心网格化** 合并：相邻同材质同朝向的面合成大四边形，
顶点里带 4 角 AO 与材质 id，因此 558 万体素只出 194 万面片、约 100 个 draw call。

**亚体素细节**：1 voxel = 4 m，在街头会占满屏幕，所以着色器为每类材质补了
程序纹理——玻璃是逐体素一扇窗（夜里随机点亮 + 微闪），圆窗幕墙是怡和大厦的
1748 个圆孔，LED 幕墙是流动色带，混凝土/石材/抹灰则叠加 **1 m 板缝 + 2 m 楼层腰线
+ 竖向雨痕**，屋面另有卷材接缝网格；这些细节只在近景生效并随距离淡出，
既把"大方块"重新雕出肌理，又不会在远景产生摩尔纹。

**曝光标定**（这一版专门校过"太阳过曝"）：辉光的亮度门槛随昼夜自适应——
白天抬到 1.16（避免太阳与天空烧成纯白），夜里压到 0.76（让霓虹与亮窗充分进辉光）；
渐进上采样增益 0.55、合成系数 `0.17 + 0.34·夜`；天空的大范围太阳光晕从
`pow(cosθ, 6)·0.35` 收窄压暗到 `pow(cosθ, 13)·0.20`，日面从 ×6 降到 ×3，
迎光雾的加亮也从 0.75 降到 0.55。探针新增 `whitePx / nearWhitePx`（三通道同时
≥250 / ≥243 的像素占比）作为过曝的客观判据：迎着落日的机位从 **5.4% → 1.7%**
（只剩日面那一小块该有的过曝核心），其余机位全部 0，夜景亮度维持在校正前水准。
连续网格共享顶点（维港本体 4 voxel，向外延伸后振幅渐隐为 0，再用 128 voxel
的平静水面铺到地平线），顶点只承担 3 个大尺度涌浪的位移（振幅 ≈0.9 m，
台风天 ×2.1），细节全部交给逐像素解析法线：8 个方向波谱从 384 m 涌浪一直到
8 m 涟漪，按距离分三级淡出，因此近处有细碎波纹、远处不会闪成噪点。
着色走 Schlick 菲涅尔（F0=0.02）+ GGX 太阳镜面（那条金色光路）+ 碎浪闪烁 +
平面反射（法线扰动随距离收敛）+ 深浅水体色 + 逆光通透 + 随涌浪进退的岸边泡沫 +
风大时的浪脊白头 + 雨点涟漪 + 夜间岸灯光带；**海面同样采样阴影图**，
所以低太阳角下高楼与船只会在水上压出暗带、镜面高光随之熄灭。

## 4. 世界坐标

```
+X = 东（0 → 1152：坚尼地城/西九龙 → 鲗鱼涌/土瓜湾）
+Z = 北（0 → 704：太平山 → 港岛北岸 ≈218-249 → 维港 → 九龙南岸 ≈426-473 → 九龙群山）
+Y = 天（海平面 SEA=8，填海区地面 GROUND=9，上限 176 ＝ 704 m）
```

港岛平地只有岸线往南 ~240 m，之后地形抬升——所以城市自然形成
「沿岸高楼 + 半山台地住宅 + 山顶留林」的三段式剖面，和真实香港一致。

## 5. 验证工具（`_test/`）

无需浏览器（纯 Node，秒级）：

```powershell
node _test\gen.cjs "core,volume,geo,build,landmarks,extra,city,detail"   # 生成 + 俯视 ASCII 地图 + 体素/网格统计
node _test\check.cjs                                                     # 结构体检（见下）
node _test\controls.cjs                                                  # 操作轴向体检（加载真 three.js 验相机基向量）
```

`check.cjs` 的断言：地块坐实（无悬浮楼）· 孤立体素（区分细线构件与结构事故）·
地标高度与锚点可分辨性 · 半山住宅海拔分布 · 第一人称落脚点净空 · 显存/批次/体素预算。

`controls.cjs` 的断言：第一人称与上帝视角的 `W/A/S/D` 是否严格对上相机的
前方与屏幕右方（各 32–45 组 yaw/pitch 组合），并回归验证旧代码的两个方向错误；
另外核对步行/疾跑速度与跳跃高度是否落在真人区间。

`_test\shots\` 里留了一组无头渲染出来的样张可以直接打开看：
`harbour / overview / central / kowloon / peak`（黄金时刻 17:54）与
`harbour_night / promenade_night / nathan_night / shelter_night`（幻彩咏香江 20:30），
另有 `*_storm` 台风雨与 `*_noon` 正午街头。

需要浏览器（无头 Chrome + SwiftShader；**用 pwsh 运行**，脚本为纯 ASCII 以免旧版
PowerShell 的编码问题）：

```powershell
pwsh -File _test\shots.ps1 -Views "harbour,central,nathan" -Query "t=20.5" -W 960
pwsh -File _test\probe.ps1 -Views "harbour" -Query "t=18.6"      # 只要统计与 ASCII 图
pwsh -File _test\decode.ps1                                      # 从已有 dom.txt 再解一次图
```

`-Views` 既接受探针内置机位（`harbour / overview / central / kowloon / peak /
street / promenade / ifc / water`），也接受面板上的经典机位名（`nathan / shelter /
corridor …`）。探针会在页面里追加 `<pre id="probe">`：每个视角一行 JSON（体素/面片/
draw call/HDR 格式/太阳高度/平均亮度/亮暗像素占比/相机位置/GPU 名）+ 一张 100×42 的
ASCII 亮度图，另把每帧 JPEG 以 base64 塞进 `<pre class="shot">` 由脚本落盘到
`_test\shots\`；页面还会截流 `console.warn/error`（着色器编译失败只走这里，
不看它就会像本轮那样"画面变黑却查不出原因"）写进 `_test\console.txt`。
因此**即使不看图，也能判断画面是否点亮、构图是否成立、有没有黑洞**
（`darkPx` 最灵敏：远场海面修好后维港全景的 `darkPx` 从 0.035 → 0；
水面着色器一旦编译失败，它会立刻飙到 0.5）。

## 7. 调参位置

| 想改什么 | 改哪里 |
|---|---|
| 体素粒度 / 世界尺寸 | `core.js` 的 `W.VOXEL / SX / SY / SZ`（注意显存随面片数增长） |
| 城市密度、分区性格、楼高区间 | `city.js` 的 `HK_DISTRICTS / KL_DISTRICTS`（`hMin/hMax/mats/styles/ac/sign/lot`） |
| 建筑原型的比例 | `archetypes.js` 的 `A.choose()` 权重（`add('tenement', 6)` 这类），新增原型只要往 `T` 里加一个函数 |
| 画质档位（分辨率/阴影/辉光/体积光/锐化） | `app.js` 的 `QUALITY` 表 |
| 体积光强度 | `app.js` `applyLook()` 里的 `strength * 0.30`，衰减在 `gfx.js` 的 `shafts` 着色器 |
| 过曝 / 辉光门槛 | `app.js` 的 `uThreshold = 1.16 - 0.40·夜` 与 `uBloom = 0.17 + 0.34·夜`；太阳本体在 `gfx.js` 天空着色器的 `pow(sunAmt, …)` 三项 |
| 半山住宅带的范围与限高 | `city.js` 的 `hillside()`（`kMin/kMax/hLo/hHi`，海拔上限 `W.GROUND+52`） |
| 街道细节的密度 | `detail.js` 各函数里的概率（天台屋 0.72/0.3、竹棚 0.045、天台花园 0.16…） |
| 昼夜色彩曲线 | `app.js` 的 `STOPS`（按太阳高度插值：白昼/黄金/日落/蓝调/深夜） |
| 天气 | `app.js` 的 `WEATHER`（云量/雾倍率/雨/浪高/饱和度/风暴度） |
| 经典机位 | `app.js` 的 `VIEWPOINTS`（数字键与面板 chips 自动跟随） |
| 亚体素纹理（板缝/腰线/雨痕） | `gfx.js` 体素片元着色器的 `kind < 0.5` 分支（`near` 控制淡出距离） |
| 浪的大小 / 细节层级 | `gfx.js` 的 `WAVES` 波谱（方向 / 波长 / 振幅 / 相速）与片元里的 `lodA/B/C` |
| 水色、菲涅尔、镜面粗糙度 | `gfx.js` `waterMaterial` 的 `uDeep / uShallow` 与 `rough`（随 `uWave`、`uRain` 变化） |
| 远场海面范围 | `app.js` 的 `FAR` 与四片粗网格（`buildWaterGeometry(128, …)`） |
| 移动速度 / 跳跃 / 重力 | `app.js` 的 `SPD`、`JUMP`、`GRAV`（单位是 voxel，×4 得米） |
| 阴影柔和度 | `gfx.js` `shadowFactor()` 的抽样半径 `t` 与 `app.js` 的 `shadowSize` / `radius` |
| 光影强度、辉光、色调 | `gfx.js` 的 `composite` uniforms 与 `app.js` 的 `applyLook()` |
| 幻彩咏香江的光束阵位 | `entities.js` 的 `sources` 数组 |

## 8. 已知边界

* 单文件静态站点，不做 LOD/视锥分块流式加载：整城一次性上传显存（≈133 MB），
  低端集显建议加 `?scale=0.8&shadows=0&refl=0`。
* 1 voxel = 4 m 是「城市尺度可读」与「浏览器显存」之间的折中；改到 2 m 会让
  面片数增到 4 倍左右，需要配套做分块剔除。
* 地理是**写实概化**：海岸线、地标位置与高度按真实数据摆放，但街区尺度做了
  规整化（一街区 ≈ 26 voxel ＝ 104 m），不是测绘级底图。
