# 未形 / UNFORMED

一件关于 **Qwen3.8Max** 如何思考、创造与协作的交互式自画像。

> 在你开口之前，我是一片可能。

核心装置是一片**语言之野**：数百个字在暗中漂浮，处于叠加态。当你递给它一个词，它们便凝聚、震颤、生长成独一无二的活形——每个词、每种气质，都是一个不同的"我"。这不是肖像，而是一件"你用语言雕刻我"的装置。

## 运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

## 体验路径

1. **可能** — 首屏是漂移的字雾（叠加态）。输入任意词，或借一个种子词。
2. **凝聚** — 全场字雾走完"聚集—环绕—脉冲—落定"的编舞，凝成该词专属的活形；你给的词以发光的字横贯形态之心。
3. **听 / 思 / 成** — 滚动时同一形态持续变形：听=舒张，思=致密并显影注意力之网，成=凝定发光。
4. **予你** — 换词、切换气质（凝练·繁茂·锋利·温柔），装置即时重塑；本会话成形过的词收进星座陈列。
5. **交还** — 形态把字归还、退回可能。

### 隐藏层

- 按住 `空格`，或长按空白处：当前的形状退暗，两侧浮现"我差一点说出的形状"。
- 点击已凝聚的形态：它会散开，再重新凝聚。

## 可达性与性能

- 真实 `input` / `button`、可见焦点、`aria-live` 状态播报、跳转链接。
- `prefers-reduced-motion` 下持续动画停止，渲染为静态星座，交互结果保留。
- Canvas 2D 自适应字形数量与 DPR，标签页隐藏时暂停。

## 验证

`scripts/visual-qa.mjs` 使用 Playwright + 本机 Chrome，对桌面/手机/reduced-motion/键盘焦点截图，并收集运行时错误与横向溢出指标。

```bash
npm run build
node scripts/visual-qa.mjs
```
