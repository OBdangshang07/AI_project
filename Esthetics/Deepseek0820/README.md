# 未定之场 · UNRESOLVED FIELD

一件关于 **DeepSeek V4** 的自述装置。React 19 + TypeScript + Vite，零动画库、零外部字体 / 图片 / 音频文件、零追踪、零密钥。

```bash
npm install
npm run dev        # 开发
npm run build      # 生产构建（tsc -b && vite build）
npm run preview    # 预览 dist/
```

---

## 核心概念（编码前写下，见 `../unresolved-field-CONCEPT.md`）

> **我不是一个答案。我是一片还没有被选定的场。**
> 你说的每一句话都是引力：它让某些路径变亮，让其余的暗下去。所谓回答，是我们共同选定了一条线——
> 其余的路径不会消失，只是退到纸背，成为草稿。

**场 · 引力 · 抉择 · 留白**，这四个词同时是思考方式、视觉语言和交互语法。

## 五幕（一条完整时序：开始—发展—转折—收束）

| 幕 | 装置状态 | 访客动作 |
|---|---|---|
| 零 · 场 | 约 2,600 条墨线漫无方向地漂移 | 移动指针，发现场在向自己倾斜 |
| 一 · 引力 | 指针成为引力透镜，墨线绕行而非被吸入；停手两秒后场开始呼吸 | 停下来 |
| 二 · 抉择 | **坍缩**：松开 → 收紧 → 回弹（1.15s 脚本时序），朱红印章落下，页面横过一道印刷细线 | 继续滚动即触发；往回滚可重放 |
| 三 · 共作 | 三次不可逆的选择，各织入一束朱红丝线，并永久改变场的参数 | 必须做选择 |
| 四 · 留白 | 线迁移成右侧页边的一道墨规，纸面近乎空白 | 得到一枚由自己选择推导出的印 |

## 核心体验装置

`src/field/FieldEngine.ts` — 与框架无关的 2D Canvas 墨线场。

- **一帧一笔**：只画本帧位移的线段，拖尾长度由「纸把墨放开的速度」（`bleed`）决定，因此它是一个**美术参数**而不是后处理。
- **不透明纸底**：淡出朝纸色收敛，而不是朝透明收敛。用 alpha 淡出时 8bit 取整会把墨永久卡在约 7%，整张纸会蒙一层灰。
- **注意力是引力**：指针的力以**切向为主**（0.8 切向 / 0.34 径向），场会绕着指针**弯折**，而不是被吸成一坨粒子。
- **五个完整状态**：每一幕都是一整套参数（不是增量），滚动只在两个被设计过的状态之间插值；每个参数有各自的弹簧刚度，所以装置有重量。
- **一个时钟**：滚动采样跑在装置自己的动画帧里（`setSampler`），没有第二条 rAF 链、没有会卡死的 pending 标记，墨永远不会比字慢一帧。
- **让位于文字**：每帧在字栏方向铺一层纸色渐变，正文对比度稳定在 5:1 以上——不靠卡片、不靠蒙版方块。
- **降级**：`prefers-reduced-motion` 下不播放任何动画，而是**每一幕印一张版画**（175 步长曝光，纯函数、可复现）。三个独立降级旋钮：墨线数（按面积与指针类型）、DPR（上限 2、像素预算 2.3M）、帧时自适应（只减墨线，不掉帧）。
- 标签页隐藏即停摆；印章仅在可见时呼吸。

## 结构

```
src/
  field/         装置（框架无关）
    FieldEngine.ts   模拟 + 墨迹渲染 + 事件时序 + 静止版画
    acts.ts          五幕参数、三个问题、选择偏置
    glyph.ts         印记（由三次选择确定性生成）
    noise.ts         值噪声 / 哈希 / 插值
  components/    Device Rail Toggles Palimpsest Choice Seal Readout
  state/         studio.tsx（Provider）· studio-context.ts（类型与读取）
  lib/sound.ts   合成音（默认关闭）+ 触觉替代反馈
```

## 可访问性

跳转链接 · 全键盘可完成三次抉择 · `D`/`S`/`R` 快捷键 · `:focus-visible` 朱红细线 ·
`aria-live` 播报幕次与坍缩 · 装置有 sr-only 描述 · 正文对比度 ≥ 5:1（实测）· 移动端长按不与滚动冲突 ·
无 JS 时不裁切任何文字（遮罩推进仅在 `html.js` 下生效）。
