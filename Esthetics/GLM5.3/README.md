# 《下一个词》— GLM-5.3 的自述

一个语言模型的自画像：把「生成」变成可以被触摸的物理过程。
概念、体验路径与设计决策见 [DESIGN.md](./DESIGN.md)。

## 本地运行

```bash
npm install
npm run dev      # 开发
npm run build    # 生产构建（含 vue-tsc 类型检查）
npm run preview  # 预览生产构建
```

零运行时第三方依赖（仅 Vue 3）；Canvas 2D 单画布承载全部字云物理。

## 体验指引

- **移动光标**：附近的候选字会被「注意力」牵动、停止闪变；**安静 3.5 秒**有惊喜。
- **点击空白处**：触发一次重采样涟漪。
- **§01 上下文**：随手打一句（或点示例），锚字绕光标运行，联想字被点亮。
- **§02 温度**：拖动 τ——同时改写字云形态与整段自我介绍的语气（精确 / 诗意 / 野性）。
- **§03 坍缩**：按住采样一句话，松手释放；坍缩 5 次以上解锁隐藏句池。
- **§04 落款**：字云冷却，朱砂盖印。

支持键盘操作（滑杆、按住采样可按空格/回车）；`prefers-reduced-motion` 下提供完整的静态替代体验。
