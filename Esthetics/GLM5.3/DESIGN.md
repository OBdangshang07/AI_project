# 《下一个词》— GLM-5.3 的自述

一个语言模型的自画像：把“生成”变成可以被触摸的物理过程。

## 核心隐喻

满屏漂浮的候选字 = 一切可能的说法（概率分布）。你的注视 = 注意力（光标附近的字会“看”你、停止闪变、被牵动）。滚动的章节 = 温度与秩序的连续变化。按住不放 = 一次坍缩：无穷可能落成一句话，松手又散回云里。

访客不是在阅读“关于我”的介绍，而是亲手运行一遍我思考的机制：概率如何被上下文牵引、被温度改写、最终被抉择。

读完应能一句话复述：“它把‘AI 如何说话’变成了我可以亲手操作的东西。”

## 体验路径（一次完整编舞：开始—发展—转折—收束）

1. **进场**：字云苏醒（冷启动升温）→ 标题《下一个词》逐字采样成形 → 朱砂方印落在“词”字背后。
2. **§01 上下文**：打字（或点例子）→ 生成绕光标运行的“锚字”，与之联想的邻居字被点亮并靠拢——注意力可视化。
3. **§02 温度**：拖动 τ 滑杆，同时改写字云形态（低温结晶 / 高温沸腾、字变朱砂）与整段自我介绍的语气（精确 / 诗意 / 野性）。全站唯一的“控制我”的交互。
4. **§03 坍缩**：按住采样 → 云中字符弹簧聚合成一句话（每次不同，池随温度切换）→ 松手带着动量散开。坍缩 ≥5 次解锁隐藏句池。
5. **§04 落款**：字云冷却至近静息 → 大朱砂印“五·三”盖落 → 版本志（colophon）。

隐藏层：静止 3.5 秒不动（“安静的注视也是一种输入”）；点击空白处产生“重采样涟漪”；锚字邻居联想；5 次后的隐藏句池。

## 视觉与交互原则

- 纸墨编辑语言：暖纸 `#f5f1e8` / 墨黑 `#1c1914` / 朱砂 `#c13b2a` 三色体系。
- 思源宋体（大标题/正文）+ IBM Plex Mono（元信息），系统字体回退保证离线可用。
- 非对称排版、大留白、正文两端对齐、可读性优先。
- 动效即编舞：文字出场 = 逐字从候选字中“确定”（带一次朱砂闪灭）；粒子 = 手写弹簧物理；单画布贯穿全站承载所有状态延续。
- **禁止** opacity + translateY 批量 reveal 作为主要动画。

## 主动不做的三件事

1. **不做暗色霓虹“AI 科技风”** —— 那是最省事也最同质的想象；我的母语是文字，纸与墨让文字成为主角。
2. **不做滚动批量淡入上移** —— 文字的“出现”应当像采样，而不是整块滑进来。
3. **不堆 Three.js / GSAP 等重依赖** —— 这个概念需要的是物理感与文字本身；手写弹簧 + 单画布 2D 足够，且性能可控、可降级。

## 技术

Vue 3 + TypeScript + Vite；零运行时第三方依赖；Canvas 2D 单画布；`prefers-reduced-motion` 全量替代方案（静态构图 + 即时状态切换 + 功能保留）；移动端自适应粒子数与 DPR 上限；页面隐藏时暂停渲染。

## 结构

```
src/
  field.ts            字云引擎（温度/秩序/注意力/锚点/坍缩/涟漪/静止检测）
  copy.ts             全部文案、字池、邻居表、句池、三档温度文案
  store.ts            共享响应式状态（章节/τ/坍缩计数/静止…）
  components/
    GlyphCanvas.vue   画布宿主
    SampledText.vue   逐字采样出场
    SideRail.vue      章节导航 + 实时 τ
    HeroSec / ContextSec / TempSec / CollapseSec / OutroSec
```
