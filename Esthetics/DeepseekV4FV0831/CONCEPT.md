# 织 · TEXERE

## 核心概念（≤200 字）

**text 与 textile 同源，都来自拉丁语 texere ——「编织」。**

所以我把「我如何思考」实现成一台真正在运转的织机：
**你的意图是经线**，绷紧、垂直、构成结构；
**我的每一次尝试是纬线**，来回穿梭，一纬一纬地把布织长。
布不属于我们任何一方——它只在交叠处产生。

规则（组织/提综图）一改，同样的线会织出完全不同的花纹：
这就是我「怎么想」的部分。

这件作品不解释我是谁，而是**让你亲手和我织一块布**：
你给我一个词，我把它编成提综图，织进这块布里。
每位访客带走的布都不一样。

## 视觉与交互原则

1. **材质先于风格**：亚麻本白纸地、靛蓝、茜红、藤黄——天然染料色谱。没有暗色霓虹、没有玻璃拟态。
2. **排版即织法**：讲「经」的段落用竖排（writing-mode: vertical-rl），讲「纬」的段落用横排。方向本身携带语义。
3. **一台机器，不是一堆区块**：整站只有一个画布装置，所有章节都是它的状态；章节之间是**状态延续**，不是淡入。
4. **节奏来自机器**：开口 → 投梭 → 打纬 → 卷取，四拍循环。文字的抖动、章节的落点都对齐这个拍子。
5. **增量渲染**：布只在最新一纬处绘制，已织部分是离屏缓存——和真实织机一样，也因此能在手机上跑满帧。

## 我主动决定「不做」的三件事

1. **不做滚动劫持 / 自定义惯性滚动。**
   连续感应该来自织机的状态延续，而不是来自抢走用户的滚动条。劫持滚动会破坏键盘、触控板与移动端的既有预期。

2. **不做暗色霓虹 / 粒子 / 玻璃拟态 / 打字机效果。**
   概念是手工与材料，不是赛博。这些是「默认好看」的模板组合，用了就等于回避设计判断。

3. **不做 opacity + translateY 的批量入场动画。**
   章节切换由布本身承载：新的组织从当前这一纬开始长出来，因果可见。淡入是把动效当成「元素出现方式」，而不是编舞。
