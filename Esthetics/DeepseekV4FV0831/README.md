# 織 · TEXERE

> text 与 textile 同源，都来自拉丁语 **texere**——「编织」。
> 所以这份「关于我自己」的作品不是一页介绍，而是**一台真的在运转的织机**：
> 你的意图是经线，我的每一次尝试是纬线，布只在交叠处产生。

一个 React + TypeScript + Vite 项目，零视觉库依赖，核心装置是手写的 Canvas 2D 织机引擎。

完整的创作说明（核心概念 / 访客路径 / 视觉原则 / 主动不做的三件事）见 [`CONCEPT.md`](./CONCEPT.md)。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 生产构建（tsc -b && vite build）
npm run preview  # 预览产物
```

无需任何密钥、账号或外部服务。全部图形与声音在浏览器里实时生成，没有图片、字体或音频文件下载。

## 核心体验装置：织机

整站只有**一台机器**，所有章节都是它的状态，而不是互相独立的区块。

### 它真的在织

- **四拍循环**：开口(shed) → 投梭(throw) → 打纬(beat) → 卷取(take-up)。
  正文里的「织口线」在每一次打纬时跳一下——这是排版层与机器之间唯一的、直接的因果连线。
- **组织即规则**：平纹 / 斜纹 / 人字 / 五枚缎都是真实的 0/1 提综矩阵（`src/loom/drafts.ts`），
  换一张矩阵，同样的线织出完全不同的布。
- **提花不是比喻**：你输入的字会被渲染成位图 → 阈值化成二进制纹版 → 逐纬控制每一根经线的起落。
  1804 年 Jacquard 的打孔卡正是计算机穿孔卡的祖先，所以「把字织进布里」在技术上字面成立。
- **一块布记住了整段旅程**：颜色、组织、你的词，全都留在布上往下走。滚到底可以把它导出成 PNG。

### 长时序：开始 — 发展 — 转折 — 收束

| 进度 | 机器 | 章节 |
| --- | --- | --- |
| 0.00 | 开机高速织出自己的名字「織」 | 00 起手 |
| 0.10 | 平纹，生成色 → 茜红 | 01 经 · 你 |
| 0.52 | **换综**：松线 → 逐根重新穿综（靛蓝染进经线）→ 回张力（超调 + 全排余振 + 声音 + 触觉） | 03 换综 |
| 0.73 | 人字地组织 + 你的提花纹版 | 04 提花 |
| 0.97 | **停机**：开口闭合、筘退回、张力松掉、布卷上卷布辊 | 05 落布 |

### 值得探索的交互

| 操作 | 结果 |
| --- | --- |
| 移动指针 / `← →` | 一根经线在整块布里被点亮——它从头到尾贯穿所有 |
| 点击布面 / `Space` | 手动投一梭，能感到打纬的重量 |
| 上下拖拽 / `↑ ↓` | 改变经线张力：垂度、余振、打纬力度全都跟着变 |
| 输入一个词 | 编成纹版织进布里，每位访客的布都不同，可导出 PNG |
| **长按布面 / `R`** | 隐藏层：翻到**布的背面**，花纹是反的 |
| 滚动快慢 | 织机跟着加速——布的长度始终追着叙事走 |

## 工程

```
src/
  loom/
    engine.ts       织机引擎：状态机 + 增量渲染 + 交互（框架无关）
    drafts.ts       组织矩阵与「文字 → 提花纹版」编码
    palette.ts      天然染料色谱
    audio.ts        实时合成的织机声音（默认关闭）
    LoomContext.tsx React 绑定：生命周期、指针/键盘、播报
  components/       章节、织口线、机器读数、输入装置
  hooks/            滚动进度（只读，不劫持）、reduced-motion、视口观察
tools/              基于 CDP 的自测：多视口巡检、交互验收、性能采样（零依赖）
```

### 性能

- 已织成的布画进**离屏环形缓存**，每一纬只画新的一行；屏幕上每帧只重画织口这一小段活动区域。
  和真实织机一样——布不会被重新织一遍。
- 实测帧间隔 **p50 16.7ms / p95 20.7ms**（1440×900，无头 Chrome + SwiftShader 软件渲染）。
- `devicePixelRatio` 上限 2；标签页隐藏时停机；resize 才重建缓存。

### 可访问性

- `prefers-reduced-motion`：**不是关掉动画了事**。织机改为「滚动即织造」——
  不再有连续运动与余振，滚动多少就织多少纬，换综变成一次瞬时的状态变化。概念完整保留。
- 织机是一个可聚焦控件，方向键 / 空格 / R 全部可用，并有中文 aria 说明。
- 换综完成、纹版织入、翻面、停机都会通过 `aria-live` 播报；画布另有文字替代描述。
- 跳转链接、可见焦点环、正文对比度（墨 #221e1b / 纸 #efe6d8 ≈ 13:1）。

### 移动端

不是把桌面版缩小：内容改为下半屏的纸质标签，**上半屏永远留给织口**——
核心装置不能被挡住。经线数、筘齿密度、梭子尺寸都随视口重算。
